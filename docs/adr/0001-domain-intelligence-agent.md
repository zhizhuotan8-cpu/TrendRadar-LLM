# 在现有采集与推送能力上构建大模型情报 Agent

用户于 2026-11-09 确认产品面向个人大模型应用开发工程师，以模型选型、应用架构、开发效率、运行成本和可靠性作为情报价值的主线。采用现成模型与可追溯的检索分析流程，复用现有采集、模型客户端和飞书推送；相比训练专用模型，这种方式更适合持续变化的信息，更新来源与保留证据也更直接。

每日简报与网页追问共享情报和证据记录。来源文档与事件分别建模：多篇报道可以描述同一事件，同一来源的实质更新也可以形成新版本；保留发布时间与首次发现时间，避免将晚发现的旧信息视为新进展。相比将聚合后的摘要作为唯一记录，这会增加存储与关联成本，但可以追踪后续进展、审查分析出处并重新生成结论。

技术落地仍需验证正文覆盖、事件关联质量和检索预算；本记录不表示这些能力已经实现。

已确认需求、技术设计、实施顺序和验收标准统一保存在 [GitHub Issue #1](https://github.com/zhizhuotan8-cpu/TrendRadar-LLM/issues/1)。
